# StarRocks What 系列写作索引

> 写作主旨：借 StarRocks 理解现代分布式 OLAP 数据库的设计思想。15 篇，每两天一篇，按北京时间 2026-11-10 至 2026-12-08 交付审阅稿。所有稿件先走独立分支与 Draft PR，作者审阅后合并。What 解释机制与设计取舍，How 才展开生产落地、调优与运维实战。

## 写作协议

- 统一业务场景：物流订单按日期和网点汇总，明确数据口径、正确性、新鲜度与查询 SLA。
- 固定结构：问题引入、概念定位、核心机制与图、至少两种方案取舍、验证及故障路径、作者练习与关键审稿问题。
- 去重键：领域 + 核心设计问题 + 决策边界。以官方英文文档、规范和原始论文为依据。
- 证据分级：F = 官方事实；H = 条件推断/待验证假设；O = 真实观测（须有版本、环境、原始指标）。不得编造实验。
- **交付状态**以 PR 为准，未合并的审阅稿不等于已正式发布。
